# Skill Bridge Platform

Skill Bridge is a web platform designed to bridge the gap between education and employment by helping learners develop practical skills through challenges, certifications, and performance tracking.

## Live Demo

https://b-skill-bridge.vercel.app/

## Project Overview

The platform provides learners with opportunities to improve their skills through practical tasks and challenges while enabling administrators to manage users, content, and learning progress through a dedicated dashboard.

## Features

- User Authentication
- Student Dashboard
- Admin Dashboard
- Skill-Based Challenges
- Task Submission System
- Certificate Management
- Notification System
- Points & Rewards System
- Progress Tracking
- Responsive Design

## Technologies Used

- React.js
- Tailwind CSS
- Framer Motion
- Supabase
- Local Storage
